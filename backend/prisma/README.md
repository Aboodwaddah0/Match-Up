|---|---|

## Constraint / trigger map

| Rule | Enforced by |
|---|---|
| Match never exceeds capacity | `fym_participant_guard` (locks match row, counts CONFIRMED, then allows) |
| OPEN/FULL always consistent with count | `fym_participant_after`, `fym_match_guard` (capacity edits) |
| Player not CONFIRMED in 2 overlapping matches | `participant_no_overlap` (gist exclusion on user + time range) |
| No overlapping PENDING/CONFIRMED bookings per field | `booking_no_overlap` (gist exclusion) |
| Blocks never overlap each other | `venue_block_no_overlap` |
| Booking vs block never overlap | field-row lock + `fym_booking_guard` / `fym_venue_block_guard` |
| 2h hold, lazy expiry, confirm-vs-expiry race | `fym_booking_guard` (DB `now()`) |
| Max 3 simultaneous pending holds per user | `fym_booking_guard` + advisory lock |
| One pending request per (match, user) | partial unique `uq_match_request_one_pending` |
| Requests only for OPEN, OPEN_MATCH, public/invited, unblocked | `fym_request_guard` |
| Match lifecycle state machine, 48h CLOSED_UNCONFIRMED, 7d recovery | `fym_match_guard` (admin override via `set_config('fym.actor_is_admin','true',true)`) |
| Time/format locked once someone is confirmed | `fym_match_guard` |
| Cancel frees slots; start expires pending requests; completion finalizes attendance | `fym_match_after_status` |
| Leave only before start; late-cancel flag (<12h) | `fym_participant_guard` |
| TEAM_CHALLENGE: no capacity, no requests, exactly 2 sides, roster per side | CHECK + `fym_request_guard` + deferred `fym_match_teams_complete` + participant guard |
| Reviews: completed match, both attended, 7-day window, once per pair | `fym_review_guard` + unique |
| Booking shape (IN_APP vs EXTERNAL) | `chk_booking_source_shape` |
| Outbox row holds its secret exactly while sendable; claim / finished / sent shape (MAIL-01, migration `20261118000100_mail_outbox`) | `chk_mail_outbox_secret_lifecycle`, `chk_mail_outbox_claim`, `chk_mail_outbox_finished`, `chk_mail_outbox_sent`, partial indexes `idx_mail_outbox_*` |
| One push per (notification, device); an accepted push cannot silently return to PENDING; the device token snapshot lives exactly while the delivery does; one shared send channel state and rate bucket (NOTIF-01, migration `20261118000200_push_delivery`) | `push_delivery_notification_id_device_token_id_key`, `chk_push_ticket_phase`, `chk_push_token`, `chk_push_claim` (send lease exactly while SENDING), `chk_push_receipt_lease` (receipt lease only on an ACCEPTED row), `chk_push_finished`, `chk_push_state_paused`, `chk_push_state_probe`, `chk_push_bucket_single`, partial indexes `idx_push_delivery_*` |
| Admin audit log is append-only (AUD-01, migration `20261117000400_admin_audit_log`) | `trg_admin_audit_immutable` refuses UPDATE / DELETE and `trg_admin_audit_no_truncate` refuses TRUNCATE (both `fym_audit_immutable`; a superuser can still disable them, see the migration header); `chk_admin_audit_reason_length`, `chk_admin_audit_metadata_object` |

## Error codes the service must map
Triggers raise `FYM_*` (SQLSTATE `P0001`); constraints keep standard codes: `23P01` overlap, `23505` duplicate, `23514` shape/range.
Assumes `READ COMMITTED` (PostgreSQL default).
